# Credit Risk & Loan Default Analysis
 Objective-Analyse borrower and loan characteristics associated with loan default, identify higher-risk borrower segments and use statistical and machine-learning techniques to support credit-risk assessment.
Dataset-Lending Club loan dataset containing 100,000 loan records.
The target variable was defined as:
Default = Charged Off or Default
Non-default = Fully Paid
Tools-Python | PostgreSQL | Excel | Machine Learning
Analysis Performed:
Data cleaning and exploratory data analysis
Creation and validation of a default flag
Default-risk analysis across borrower and loan characteristics
Credit-grade and borrower segmentation
Logistic Regression and machine-learning analysis
SQL-based portfolio and risk analysis
Excel-based analysis and reporting
Key Analysis:
Analysed overall loan portfolio size, exposure and default risk
Compared default rates across credit grades and loan purposes
Analysed risk across income bands and employment length
Examined interest rates and debt-to-income ratios across loan outcomes
Analysed default risk by loan term, home ownership and verification status
Identified higher-risk borrower segments based on credit grade and income
Analysed default risk across different interest-rate bands
Business Application:
The analysis can support credit-risk assessment by identifying borrower and loan characteristics associated with higher observed default rates, highlighting higher-risk borrower segments and providing insights that can assist lending and portfolio-risk decisions.
